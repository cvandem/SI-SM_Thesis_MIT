# SI-SM_Thesis_MIT

Accompanying code for the SM thesis: Design and Experimental Validation of Neuromorphic Circuits in Mammalian Cells.

## Description

MIT_M.py plots predictions for the "M" netowrk characterized in Figure 7a, 7e, and 7i.

MIT_I.py plots predictions for the "I" netowrk characterized in Figure 7b, 7f, and 7j.

MIT_T.py plots predictions for the "T" netowrk characterized in Figure 7c, 7g, and 7k.

MIT_DOT.py plots predictions for the "DOT" netowrk characterized in Figure 7d, 7h, and 7l.

.pkl files contain (greater than one and less than one) ratios interpolations.

### Dependencies

Python 3.12 

seaborn 

colorcet 

matplotlib 

numpy 

pickle 

json

### Installing/Executing

Download all files to the same directory. Execute all code from that directory. Each .py file can be executed independently.
